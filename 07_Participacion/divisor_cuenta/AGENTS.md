# Instrucciones del proyecto
App Flutter de una pantalla para dividir una cuenta.
Capas: lib/presentation, lib/domain y lib/data.
Dependencias: presentation -> domain <- data. Domain es Dart puro: no importa Flutter.
Usar null safety, nombres en español y ningún paquete externo adicional.
No modificar test/ salvo petición expresa; la guía del ejercicio autoriza crear sus pruebas.
No añadir dependencias al pubspec sin avisar. No modificar android/ ni ios/.
main.dart es el punto de composición.
Comandos: flutter pub get, flutter run, flutter analyze, flutter test.
